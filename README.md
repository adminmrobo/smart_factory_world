# 스마트 팩토리 World

공장 하나를 **World**(구역 · 데이터 · AI 에이전트 · 사람 · 규칙)로 정의하고, 같은 정의에서 3D 디오라마 · 동적 대시보드 · 강의 해설을 만드는 저장소입니다. AI가 먼저 일하고(제안), 사람은 값을 매기고 선을 긋고 승인합니다 — 그 흐름이 공장 위에 기록으로 쌓입니다.

**▶ 바로 보기:** https://adminmrobo.github.io/smart_factory_world/

글 · 안상선 ((주)M-Robo 대표) · Ahn Sangsun

> 모든 공장은 교육용 가상 공장입니다. 데이터·단가·지연 시간은 수업용 가상값이며 실제 기업·공장 수치가 아닙니다.

## 구조 — 업종 > 챕터

첫 화면은 **업종 카드**(3D 썸네일)만 보여 주고, 업종을 누르면 그 업종의 **챕터**가 모입니다.

```
index.html                 업종 목록
cement/                    시멘트 제조업
  index.html               업종 허브 — 챕터 카드(3D 썸네일)
  world.json               이 업종의 World 정의
  img/                     썸네일(3D 장면 캡처)
  factory/                 챕터 1 · 공장 World
  strength/                챕터 2 · 28일 타임머신
```

## 업종

| 업종 | 챕터 | 연결 강의 |
|---|---|---|
| [시멘트 제조업](cement/) | ① [공장 World](cement/factory/) v0.4 — 가마 37분 · 병목 신호판 · 결정 기록<br>② [28일 타임머신](cement/strength/) v0.1 — 생산일 강도 예측 → 28일 압축 시험<br>③~⑤ 연료 절감 · 경계선 · 폐자원 연료 (준비 중) | [AI를 활용한 시멘트 공정 최적화](https://adminmrobo.github.io/AI_for_cement_produce/) (15주) · AI 활용 제조현장 AX 실무 전문강사 양성과정 |
| 자동차부품 · 조선기자재 · 석유화학 · 비철금속 · 이차전지소재 · 플랜트기계 | 준비 중 — 병목 진단 실습의 6개 업종 | |

새 업종을 더할 때: `<업종>/world.json` → `<업종>/<챕터>/index.html` → 썸네일을 `<업종>/img/`에 → 업종 허브와 첫 화면에 카드 추가.

## World 하나의 구성

| 파일 | 내용 |
|---|---|
| `world.json` | 구역(공정 단계)과 병목 5신호(처리 능력 · 가동률 · 재공재고 · 불량률 · 교체시간), 데이터 열 매핑, AI 에이전트의 할 수 있는 일·막힌 일, 사람의 결정 의자, 승인 규칙, 시나리오, 강의 주차 매핑 |
| `<챕터>/index.html` | 3D 장면 + 동적 대시보드. 단일 파일, 설치 없음(three.js는 CDN) |
| `README.md` | 그 World의 지도 · 데이터 출처 · 규칙 표 |

### 대시보드 탭

1. **공장** — 3D 디오라마, 시간 재생, 센서·예측 지표, World 기록
2. **병목 신호판** — 5신호 표 · TOC 5단계 · 시나리오 슬라이더 · AI 검증 실습
3. **결정 기록** — 제안 → 관문(규칙) → 승인 · 차단, 결정 의자, 하네스 4계층
